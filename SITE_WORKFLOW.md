# Site Workflow

## Обязательный порядок работы по сайту

Этот порядок считается обязательным для любых изменений по сайту.

1. До любых правок в коде сначала делается dev-версия, preview или другой безопасный визуальный показ того, как изменение будет выглядеть.
2. Эта dev-версия обязательно показывается пользователю до внесения правок в код.
3. Правки в код вносятся только после явного утверждения пользователем.
4. После утверждённых правок изменения локально проверяются ещё раз.
5. Выкладка на сервер делается только через терминал и только с участием пользователя.
6. Самостоятельно выкладывать на сервер без пользователя нельзя.

## Короткая формула процесса

`dev-версия -> показать -> утвердить -> править код -> проверить -> вместе через терминал на сервер`

## Исключения

Исключения из этого порядка допустимы только по прямой отдельной просьбе пользователя.
